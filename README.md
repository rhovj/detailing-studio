# BLACKOUT // Премиальный детейлинг автомобилей

Современный, отзывчивый и стильный Landing Page для студии автодетейлинга премиум-сегмента. Проект разработан как концепт коммерческого сайта с акцентом на высокую скорость загрузки, дорогой визуал и идеальную адаптивность.

🔗 **[Смотреть живой сайт (Live Demo)](https://rhovj.github.io/detailing-studio)**

## 🎯 Цель проекта
Продемонстрировать навыки создания коммерческого интерфейса: от работы со шрифтами и темной темой в дизайне до чистой кроссбраузерной верстки, которая одинаково круто смотрится как на 4К мониторах, так и на экранах старых смартфонов.

## 🛠 Технологический стек и фишки:
*   **HTML5:** Семантическая структура (`<header>`, `<section>`, `<nav>`, `<footer>`) для лучшего SEO.
*   **CSS3:** Использование CSS-переменных для быстрой смены темы, гибкая сетка **CSS Grid** для блока услуг, **Flexbox** для навигации.
*   **Адаптивность:** Использование `@media` запросов для перестроения интерфейса под мобильные устройства.
*   **UI/UX фишки:** Размытие заднего фона (`backdrop-filter`) для закрепленной шапки, плавный скролл к секциям, мягкие анимации при наведении на карточки и кнопки.

## 🚀 Как запустить проект локально:
1. Склонируйте репозиторий: `git clone https://github.com`
2. Откройте файл `index.html` в любом современном браузере.
